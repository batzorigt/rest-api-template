# rest-api-template

Layered REST API template: Javalin + Ebean + PostgreSQL, Java 25.
Full design: `docs/architecture.md` · agent contracts: `AGENTS.md`

## Podman instead of Docker?

Symlink `podman` as `docker`:

- Linux/macOS: `ln -s $(which podman) /usr/local/bin/docker`
- Windows PowerShell:

```powershell
$podmanDir = "$env:LOCALAPPDATA\Programs\Podman"
New-Item -ItemType SymbolicLink -Path "$podmanDir\docker.exe" -Target "$podmanDir\podman.exe"
```

## Build

```bash
./build.sh        # Linux/macOS — package + AppCDS
build.bat         # Windows
mvn package       # manual alternative
```

## Run

Scripts read the ebean-agent version from `pom.xml` and use `src/main/jib/ebean-agent-<version>.jar` (generated by `mvn package`, not in git).

```bash
./run.sh          # Linux/macOS
run.bat           # Windows
```

Manual:

```bash
java -javaagent:src/main/jib/ebean-agent-<ebean-version>.jar \
     -Dlog4j2.formatMsgNoLookups=true \
     -Dlog4j2.contextSelector=org.apache.logging.log4j.core.async.AsyncLoggerContextSelector \
     [-XX:+UnlockDiagnosticVMOptions -XX:+AllowArchivingWithJavaAgent \
      -XX:+UseZGC -Xshare:on -XX:SharedArchiveFile=app-cds.jsa] \
     -jar target/rest-api-template-1.0.0.jar
```

## Docker

```bash
docker build -t rest-api-template .
docker run -p 8080:8080 -e DB_HOST_NAME=host.docker.internal -e DB_PASSWORD=password rest-api-template
```

Podman: add `--format docker` to `build`; use `host.containers.internal` for `DB_HOST_NAME`.
Jib alternative: `mvn jib:buildTar && docker load -i target/jib-image.tar`.

## Architecture

```
http request --> access control --> handlers --> services --> orms --> rdb
```

Route-level RBAC via an `Authorization` handler wrapper; routes declare minimum role (`USER < MANAGER < ADMIN`); token missing/invalid → 401, role too low → 403; role-less routes are public. Handlers validate input and call services; services hold business logic over Ebean entities; helpers cover mail, validation, templating, crypto, tokens, i18n. Details: `docs/architecture.md`.
